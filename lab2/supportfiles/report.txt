winning path by one player blocks the other player's path, so both players cannot win and a completely filled Hex board cannot end in a draw.

2. Performance Comparison

For a 250×250 board with 50,000 moves:

Quick-Find: 11272 seconds
Quick-Union: 48 seconds
Weighted Quick-Union + Path Compression: 29 seconds

Quick-Find takes O(n) per operation. Quick-Union is O(n) in the worst case because trees can become tall. 
Weighted Quick-Union keeps trees short by attaching smaller trees to larger ones, while path compression flattens the trees. 
Its amortized cost is effectively O(α(n)), which is nearly constant.
